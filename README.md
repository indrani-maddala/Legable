# LEGABLE

Frontend prototype for packaged commodity label compliance checks.

This first step includes the global layout, navigation, and dashboard only. Other screens are placeholders.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run preview` — preview the production build
